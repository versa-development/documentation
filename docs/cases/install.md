## 1. Download Resource
* Before installing, make sure you have all the [Required Resources](/cases/requirements)
* Download the `Versa Cases` asset from your [Cfx.re Portal](https://portal.cfx.re/assets/granted-assets). 
  * The account you login with on the portal must be the same account you used to [Checkout on our store](https://store.versadevelopment.net/).

## 2. Install Files
::: warning
Do not rename the `versa_cases` folder otherwise the script will not work correctly.
:::
* Drag & drop the folder into your server files.
* Add `ensure versa_cases` to your server cfg file.

## 3. SQL Schema
* All the database tables for the Cases Script **automatically** install themselves when the script starts for the first time.
  * The only interaction the cases script has is storing a lifetime history of all cases used.

## 4. Configure Script
* Inside the `versa_cases` folder there is a `config` folder which contains config file(s).
* There are comments next to all config options explaining what that value does- if you need support regarding the config of your script or want a config option added, feel free to open a ticket on our [Discord server](https://discord.com/invite/FsrujTDbvg).
