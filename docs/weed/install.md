## 1. Download Resources
* Before installing, make sure you have all the [Required Resources](/weed/requirements)
* Download the `Versa Weed` and `Versa Weed (Props & Animations)` assets from your [Cfx.re Portal](https://portal.cfx.re/assets/granted-assets). 
  * The account you login with on the portal must be the same account you used to [Checkout on our store](https://store.versadevelopment.net/).

## 2. Install Files
::: warning
Do not rename the `versa_weed` or the `versa_weed_props` folders otherwise the script will not work correctly.
:::
* Drag & drop the files into your server files.
* Add `ensure versa_weed` & `ensure versa_weed_props` to your server cfg file.

## 3. SQL Schema
* All the database tables for the Weed Script **automatically** install themselves when the script starts for the first time.

## 4. Configure Script
* Inside the `versa_weed` folder there is a `config` folder which contains multiple config files for growing & bagging systems.
* There are comments next to all config options explaining what that value does- if you need support regarding the config of your script or want a config option added, feel free to open a ticket on our [Discord server](https://discord.com/invite/FsrujTDbvg).
